# The known differences between rucc and the reference GCC, each with the rucc issue that owns it.
# The columns are globs: row, flag set, key. check takes the first line that matches.
#
# row       set         key                                   issue

# -m32 on the x86_64 targets.
# GCC defines _Float16 there, and from GCC 14 also __bf16. rucc has neither type on 32 bit x86.
*-x86_64    m32*        __FLT16_*                             tamnd/rucc#4324
*-x86_64    boot-i386   __FLT16_*                             tamnd/rucc#4324
*-x86_64    m32*        __BFLT16_*                            tamnd/rucc#4324
*-x86_64    boot-i386   __BFLT16_*                            tamnd/rucc#4324

# A macro that still differs from the GCC of the persona: the _BitInt width.
